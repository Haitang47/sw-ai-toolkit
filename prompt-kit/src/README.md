# 图片转 SolidWorks 建模提示词包

把零件或机构的照片发给 AI，得到完整的 SolidWorks 建模方案：分级判断、尺寸表（每个尺寸都标出来源和置信度）、特征树、逐步建模步骤；需要时还能生成可以直接运行的 VBA 宏，自动建出初版模型。

## 三种用法，选一种

| 你用的 AI | 用哪个文件夹 | 特点 |
|---|---|---|
| Claude（Pro 及以上） | `1-Claude-Skill` | 装一次，以后直接发图；Claude 自动判断等级、自动读取对应流程 |
| ChatGPT（Plus 及以上） | `2-ChatGPT` | 做成专用 GPT 或项目，以后直接发图；GPT 可以通过链接分享给同事 |
| 任何 AI（含免费版、豆包、Kimi、通义、DeepSeek） | `3-通用提示词` | 不用安装，按等级选文件复制粘贴 |

三种方式的内容完全相同，都从同一份源文件生成。

## 分级

| 等级 | 典型例子 |
|---|---|
| L1 简单件 | 垫片、轴、法兰、平板 |
| L2 机械件 | 轴承座、电机支架、带孔系的机加工件 |
| L3 复杂外形件 | 曲面外壳、把手、注塑件、钣金件 |
| L4 装配体/机构 | 夹爪、云台、机械臂关节 |

## 一次完整的使用流程

1. 拍照：正对着拍，离远一点再放大；旁边放一枚 1 元硬币（Ø25 mm），或者直接用卡尺量一个关键尺寸。
2. 发给 AI，得到尺寸表和建模步骤。
3. 回答 AI 的"待确认问题"，它会修正尺寸。
4. 说"生成 SolidWorks 宏"（通用提示词用户发送 `5-生成SW宏.md`），在 SolidWorks 里运行宏，得到初版模型。
5. 在 SolidWorks 里继续细化：异型孔、螺纹、拔模等宏里标了 TODO 的地方手动完成。

装配体按 L4 流程做出来的配合，以后可以直接用于导出 URDF。

## 宏的可靠性

宏用到的所有 SolidWorks API 都在 SolidWorks 2025 上逐项实测过（17/17 通过），示例宏实际建出的零件体积与理论值一致。适用于 SolidWorks 2023 及以上版本。
