# 通用提示词使用说明

适用于任何能看图的 AI：ChatGPT（含免费版）、Claude、豆包、Kimi、通义千问、DeepSeek 等。不用安装，复制粘贴即可。

## 选哪个文件

| 文件 | 什么时候用 |
|---|---|
| 0-分级判断.md | 不确定零件属于哪一级，或者不确定照片够不够时，先用这个 |
| 1-L1-简单件.md | 垫片、轴、轴套、法兰、平板、简单支架 |
| 2-L2-机械件.md | 轴承座、电机支架、带孔系和筋的机加工件 |
| 3-L3-复杂外形件.md | 曲面外壳、把手、注塑件、钣金件 |
| 4-L4-装配体.md | 多个零件组成的整体，或者有运动部件的机构 |
| 5-生成SW宏.md | 拿到建模步骤后，想让 SolidWorks 自动建出初版模型 |

## 步骤

1. 打开对应等级的文件，全选复制。
2. 粘贴到 AI 对话框，填好开头【】里的内容，**至少给一个参考尺寸**。
3. 上传照片，发送。
4. 回答 AI 列出的"待确认问题"，它会修正尺寸和步骤。
5. 需要宏时，在**同一个对话**里把 `5-生成SW宏.md` 的全文复制发送。

## 运行宏

1. SolidWorks 菜单：工具 → 宏 → 新建，随便起个名字保存为 .swp。
2. 在弹出的 VBA 编辑器里，删掉原有的代码，粘贴 AI 给的完整代码。
3. 按 F5 运行。
4. 弹出"第 N 步创建失败"时，把提示原文发回给 AI，让它修正宏；或者从这一步开始手动建模。

## 小技巧

- 关键尺寸用卡尺量一下写进【参考尺寸】，比任何照片估算都准。
- 拍照时离远一点再放大，参照物和被测面放在同一平面上。
- 装配体先用 L4 拆分，再对每个零件说"开始建 P3"。
