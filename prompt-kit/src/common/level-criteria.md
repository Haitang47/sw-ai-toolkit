| 等级 | 判断标准 | 典型例子 |
|---|---|---|
| L1 简单件 | 单个零件；5 个以内的拉伸/旋转类特征就能完成；没有自由曲面，也没有需要标公差的配合部位 | 垫片、轴套、平板、简单 L 形支架 |
| L2 机械件 | 单个零件；几何规则，但孔系、凸台、筋、槽、阵列较多，或者有轴承孔、定位销孔这类需要公差的配合部位（这种情况即使特征很少也算 L2） | 轴承座、电机支架、联轴法兰、减速箱盖、夹具块 |
| L3 复杂外形件 | 单个零件；有自由曲面、变截面过渡、薄壁加拔模，或者是钣金折弯件 | 手持设备外壳、把手、旋钮、注塑壳体、钣金机箱 |
| L4 装配体/机构 | 图中是多个零件组成的整体，或者有能相对运动的部分 | 夹爪、云台、机械臂关节、铰链、减速器 |

拿不准时按高一级处理，因为高一级的流程包含低一级的全部内容。装配体里有复杂零件时，先按 L4 拆分，再让每个零件按它自己的等级单独建模。
