# SW 工具箱 使用说明

## 需要什么

- Windows 10 或 11（自带 .NET Framework 4.8，不用另外安装任何东西）
- SolidWorks 2023 及以上版本

把整个文件夹放在任意位置，双击 `SwKit.exe` 就能用，不需要安装。

## 一键导出

1. 把 SolidWorks 文件或整个文件夹拖进窗口，也可以点"选择文件"或"选择文件夹"。文件夹会自动查找里面所有的零件、装配体和工程图。
2. 在右侧勾选要导出的格式：
   - 零件 / 装配体：STEP、STL、3MF、Parasolid、IGES、钣金展开 DXF
   - 工程图：PDF、DWG、DXF
3. 按需调整选项，然后点"开始导出"。

设置会自动保存，下次打开还是一样。

### 几个要知道的地方

- **不会打扰你手头的工作。** 导出在后台另外启动的一个隐藏 SolidWorks 里进行，你可以继续在自己的 SolidWorks 里画图。
- **第一次导出要等 20–60 秒**，用来启动后台 SolidWorks。之后 10 分钟内再导出不用等；空闲 10 分钟或者关闭本程序时，后台 SolidWorks 会自动关闭。
- **导出的是磁盘上已保存的版本。** 在 SolidWorks 里还没保存的修改不会包含在内。
- **STL 默认保持模型原坐标**（不平移到正空间），导出 URDF 网格或多零件对位打印时请保持打开。
- **STEP 提供 AP214 和 AP203。** 实测 SolidWorks 的接口设成 AP242 时，实际输出的还是 AP203，所以没有提供 AP242 选项。
- 导出的扩展名统一为小写（例如 `.stl`），避免在 Linux 下（例如 ROS）因为大小写对不上而找不到文件。
- 钣金展开 DXF 只对钣金零件生效，其他零件会自动跳过。

### 出问题时

- 列表里每个文件都会显示结果；点底部"显示日志"可以看详细过程，"复制全部"可以把日志发给维护的同事。
- "文件是用更高版本的 SolidWorks 保存的"：这个文件需要用更新版本的 SolidWorks 才能打开。
- "目标文件被其他程序占用"：先关掉正在打开这个输出文件的程序（例如切片软件）。

## URDF 导出

1. 把装配体（.sldasm）拖进"URDF 导出"页面，或点"选择装配体"。程序会在后台 SolidWorks 里只读打开它，分析配合，识别关节。
2. 左边是 3D 预览（左键拖动旋转，右键拖动平移，滚轮缩放）；右边是识别出的关节。拖动每个关节的"预览"滑条，看机器人动得对不对。
3. 需要时修改关节类型、反转轴向、改运动范围，填好机器人名，点"导出 URDF"。

导出的是一个 ROS 功能包，文件夹名为 `<机器人名>_description`，**同一个包在 ROS 1（Noetic / Melodic）和 ROS 2 里都能直接编译**：

| 文件 | 用途 |
| --- | --- |
| `urdf/<机器人名>.urdf` | 网格用 `package://` 路径，ROS 里用 |
| `urdf/<机器人名>_standalone.urdf` | 网格用相对路径，直接拖进其他 URDF 查看器、PyBullet、MuJoCo 用 |
| `meshes/*.stl` | 每个连杆一个外观网格，单位米。细节特别多的连杆会自动简化到 20 万个三角形以内 |
| `meshes/collision/*.stl` | 碰撞网格，每个连杆简化到 2 万个三角形以内，MoveIt / Gazebo 做碰撞检测快很多 |
| `launch/display.launch` | ROS 1：`catkin_make` 后 `roslaunch <包名> display.launch` |
| `launch/display.launch.py` | ROS 2：`colcon build` 后 `ros2 launch <包名> display.launch.py` |
| `校验报告.md` | 导出后自动检查的结果，见下文 |

两个 launch 都会打开 RViz 和关节滑条窗口，需要 `robot_state_publisher` 和 `joint_state_publisher_gui`（ROS 桌面版自带；精简安装的 Noetic 上缺的话：`sudo apt install ros-noetic-robot-state-publisher ros-noetic-joint-state-publisher-gui`）。

**没有配合也能导 URDF**：默认「配合 + 几何」模式以配合为准；没有配合的零件，按零件形状推断关节：
- 同轴的轴和孔
- 轴承内孔
- 电机 / 舵机输出端（自动判断哪一侧是输出端）
- 光轴和直线轴承
- 导轨

如果配合把所有零件都锁死了，会自动改为只按几何。也可以手动切到「只按几何」，忽略配合重新识别，不用重新打开 SolidWorks。

推断出的关节在 3D 预览里标为紫色，并给出依据和置信度。把握不大的列为「建议」、默认不启用，在类型里改成转动或移动即可启用。零件之间留了间隙（没有接触）时，无法推断它们之间的关节，会按位置固定在最近的零件上。零件几何会缓存到 %LOCALAPPDATA%\SwKit\cache，零件没改过，第二次分析会快很多。

在三个真实装配体上，完全不看配合、只按几何推断：
- 四旋翼倾转机构装配体：4 个关节全部找对
- 测试机械臂：找到 2/3
- 无人机 + 机械臂装配体：17 个关节找到 12 个

轴线误差都是 0。

### 怎么识别关节

- 程序把每个配合换算成约束，算出两个零部件之间还剩几个自由度：剩 0 个就并成同一个连杆，剩 1 个转动就是转动关节，剩 1 个平移就是移动关节。
- **转动关节**用"同心 + 端面重合"（或铰链配合）效果最好；**移动关节**用两组面重合（或平行 + 重合）。
- **运动范围**：有角度 / 距离**限位配合**时直接读出来（显示"来自限位配合"）；没有时转动默认 ±180°，移动默认 ±50 mm，需要你改成实际值。
- **子装配体**默认会展开，按里面的配合识别关节（夹爪、舵机模块常常放在子装配体里）。这包括 SolidWorks 里的**刚性**子装配体，虽然它们在 SolidWorks 里整体不能动。不想要时，关掉顶部的"分析子装配体内部"，刚性子装配体就整体当作一个零件（柔性子装配体总是展开）。
- **闭链**会整体分析：例如一块板同时和基座、电机输出轴同心，单看每一对零件都还能转，但合起来其实被锁死了，程序会把它并进基座，不会误报关节。真正能动的闭链（例如四连杆）URDF 表示不了，会断开一处并提示。
- 螺钉、铝柱、电机外壳这类**绕自身轴对称、只能空转**的末端零件，会默认按固定连接导出，并折叠在列表最后（标着"可空转"）。
- 名字里带"桨、旋翼、轮、风扇"或 prop / rotor / wheel / fan 的零件，按**连续转动**导出。参与齿轮配合的零件保持转动。
- 齿轮、齿条、螺旋、联轴配合不会生成 URDF 的 mimic 关系，会在提示里列出来。
- 只剩约束不足（还能自由移动多个方向）的零部件，按固定连接导出并在提示里列出。子装配体里完全没有配合的零部件跟着该子装配体一起动。

### 坐标系约定

- 根连杆是装配体里**固定**的零部件；没有固定零部件时取最重的一组，并给出提示。
- 零位就是装配体当前的姿态。所有连杆坐标系都与世界坐标轴平行，原点放在关节轴上，所以 URDF 里 `rpy` 全是 0，读起来最直观。
- SolidWorks 默认 Y 向上，导出时会转成 ROS 的 Z 向上。如果你的模型本来就是 Z 向上，在顶部选"Z 向上"。
- 导出时，固定连接（空转的螺钉、垫片、约束不全的零件，以及你设成"固定"的关节）连着的零件会**并入上级连杆**，URDF 里只留下真正能动的关节。连杆和关节的名字和界面里一致，所以编号可能不连续。命令行加 `--keep-fixed` 可以保留每个固定连接。

### 导出后的自动检查

程序会把写出的 URDF 重新读进来检查，结果写在 `校验报告.md`，界面右侧也会显示：

- **结构**：连杆和关节构成一棵树，名字不重复，关节轴是单位向量，范围合理。
- **质量与惯量**：每个连杆的惯量矩阵正定、满足三角不等式；读到的零件质量合计与 SolidWorks 的装配体总质量一致；没设材料的零件会列出来（按 1000 kg/m³ 计算）；隐藏的零件不计入 URDF，会说明少了多少质量。
- **网格**：每个网格文件都在、不是空的，尺寸合理（能查出毫米当成米）；网格体积和质量能对上（对不上通常是网格不封闭或质量被覆盖）。
- **零位**：按读回的 URDF 计算零位姿态，每个零件的网格都要回到 SolidWorks 里的位置（误差超过 0.1 mm 算错误）。这一项能查出坐标系、关节原点写错。
- **关节轴**：每个运动关节的轴线要和配合给出的轴线重合，否则转起来会绕错轴。
- **质心**：零件网格的体积质心和 SolidWorks 算出的质心对比，独立检查网格的坐标和单位。个别零件对不上通常是零件设置了质量覆盖、含有隐藏实体或多种材料（URDF 里用的是 SolidWorks 的质量和质心，不受影响），只做提醒；大多数零件都对不上才算错误。

### 要知道的地方

- 分析的是**磁盘上已保存的版本**，装配体不会被修改，也不会在 SolidWorks 里新建坐标系。
- 第一次分析要等后台 SolidWorks 启动（20–60 秒），大装配体打开和导出网格也需要一些时间。

## 标准件库

1. 在「标准件库」页面左边选零件类型（左上角可以搜索名称、标准号或型号，例如 M3、608、GT2、LM8UU、ISO 4762，回车选第一个），右边点选规格、长度等参数，中间实时预览，并显示外形尺寸、体积和估算质量。
2. 点「生成零件」。零件在后台 SolidWorks 里用原生特征（拉伸、旋转、切除）建出来，保存为 .SLDPRT。需要的话打开底部的「同时导出 STEP / STL」。
3. 生成的文件出现在右下「已生成」列表里，**按住拖进 SolidWorks 的装配体窗口**就能插入。

一共 60 种零件，9 个分类：

| 类别 | 零件 |
| --- | --- |
| 紧固件 | 内六角圆柱头 / 沉头 / 半圆头螺钉、十字盘头螺钉、外六角螺栓、法兰螺栓、紧定螺钉（平端 / 锥端 / 凹端）、六角螺母、尼龙锁紧螺母、法兰螺母、平垫圈、大垫圈、弹簧垫圈、圆柱销、弹性销、抽芯铆钉、热熔铜螺母、铜柱、型材 T 型螺母 |
| 轴承 | 深沟球轴承、法兰轴承、推力轴承、带座轴承 UCP / UCF |

**装配生成**（选「装配生成」分类）：

- **齿轮副（按中心距）**：输入中心距和传动比，自动列出可行的模数和齿数方案。能凑整的用标准齿轮，凑不整的用变位齿轮精确凑出中心距，同时检查根切。生成的装配体带 SolidWorks 齿轮配合，拖动一个齿轮，另一个会跟着转；可以选择同时生成带轴承孔的安装板。
- **铝型材框架**：输入长 × 宽 × 高和型材系列（2020 / 3030 / 4040），生成 12 根型材 + 16 个角码的立方框，附切割清单（每种长度几根）。
- **同步带传动**：输入两个带轮的齿数和大致中心距，自动选标准闭口带长、反算精确中心距，并检查啮合齿数。

生成的装配体都会做干涉检查，结果显示在底栏。

几个要知道的地方：

- 文件默认保存在 `文档\SW工具箱\标准件\<类别>\`，可以在底部更改。同一个规格生成过，就直接使用已有文件，不再启动 SolidWorks。
- 每个零件都带自定义属性（名称、标准、规格、Description、材料说明），工程图明细表可以直接引用。
- 螺纹按光杆画（和 Toolbox 的简化画法一样）。
- 以下是简化外形：轴承、T 型槽内腔、带轮和链轮齿形、挡圈耳部、槽钢和工字钢的翼缘斜度。电机、舵机、开发板是包络外形，误差约 ±0.5–1 mm，质量请按实物另设。
- 生成后会把 SolidWorks 算出的体积和理论体积对比，确认建模没有出错。全部 207 个样本规格都在 SolidWorks 里验证过，体积误差最大 0.135%（齿轮）。

## 应力分析

第一次用，可以先点页面上的「示例：L 形支架」或「示例：悬臂块拓扑优化」，约束和载荷都已经设好，直接看效果。页面上方有一条分步引导，会提示现在该做哪一步；「使用指南」里有完整说明。

1. 把零件（.sldprt、.step 或 .stp）拖进「应力分析」页面。.sldprt 会在后台 SolidWorks 里转成 STEP，并读出零件的材料。
2. 右侧选材料，按类别分组，共 33 种：
   - 钢、不锈钢：Q235、Q355、45 钢、40Cr、65Mn、灰铸铁、304、316、17-4PH
   - 铝合金：6061-T6、6063-T5、7075-T6、2A12、5052、压铸铝
   - 钛合金：TC4、TA2
   - 铜合金：黄铜、锡青铜
   - 复合材料：碳纤维板、碳纤维管、FR4 玻纤板、玻纤尼龙
   - CNC 常用工程塑料：POM、MC 尼龙、PEEK、PC、亚克力
   - 3D 打印：PLA、PETG、ABS、PA-CF、光敏树脂

   也可以选「自定义」，自己填弹性模量、泊松比、强度和密度。
3. 在 3D 视图里**单击选面**（按住 Ctrl 多选），在弹出的条上点：
   - **固定**：螺栓孔、安装面等。至少要有一个固定面。
   - **加力**：总力（N），方向选 ±X / ±Y / ±Z，或「垂直压向面」。
   - **加压力**：压强（MPa），垂直压向面。
   - **加扭矩**：扭矩（N·m），绕所选面的轴（适合轴的圆柱面、法兰端面）。

   整个零件的重力或加速度惯性力在右侧「加重力 / 加速度」里添加。方向用零件坐标系（SolidWorks 里 Y 向上），视图里有红绿蓝三根轴对应 X / Y / Z。
4. 点「开始计算」。左上角可以切换四种显示：
   - **等效应力**：塑性材料看它。
   - **最大主应力**：脆性材料看它。
   - **位移**
   - **强度利用率**：应力 ÷ 强度，超过 100% 会失效。

   黑点是最大值的位置；「显示变形」可以看放大后的变形。

**失效判据**：
- 钢、铝、钛、铜、多数塑料是塑性材料，按 von Mises 等效应力对比屈服强度。
- 铸铁、碳纤维、玻纤、亚克力、光敏树脂是脆性材料，按最大主应力对比抗拉强度，最小主应力对比抗压强度。

安全系数取两者中较危险的位置。

**结果准不准**：

- 求解器是二次四面体单元（和 SolidWorks Simulation 的「高品质」网格同一类）。用拉杆、悬臂梁、带孔板孔边应力集中、扭转轴、自重悬臂梁的理论解核对过，误差 0.04%–2%。
- 每次计算都会给出**估计误差**（Zienkiewicz–Zhu 误差估计，能量范数）：3% 以内很好，8% 以内可以接受。同时检查求解是否收敛、外载和支撑反力是否平衡。
- **自适应加密**：只在误差大的地方加密网格并重算，直到估计误差低于 3%、离开约束面的最大应力变化小于 3%，最多 3 轮。思路和 SolidWorks Simulation 的 H 自适应相同。右侧会列出每一轮的单元数、最大应力和误差。
- **尖角**（没有圆角的内角）和**固定面边缘**的应力在数学上是无穷大，会随网格加密一直升高，这不是真实应力。程序会提示这种情况，并单独给出「离开固定面后的最大应力」；要知道尖角处的真实应力，给它加上真实的圆角再算。

**拓扑优化**（结构优化）：

1. 设好固定面和载荷（和应力分析一样），点底部「拓扑优化…」。
2. 选**保留的材料比例**（20%–60%，常用 30%–50%）和**细节程度**：粗约 2.5 万单元，标准约 6 万，细约 12 万。
3. 点「开始优化」。可以实时看到材料一点点被去掉，标准细节大约 1 分钟。
4. 结果给出保留的材料、保留的刚度（相对实心零件）和减重。点「导出 STL」得到优化后的外形（毫米），在 SolidWorks 里作为参考重新建模，再回来做应力校核。

方法是 SIMP 密度法：
- 加上体积加权的密度过滤和 Heaviside 投影，用最优准则法更新；这是学术界和商业软件最常用的方法，参考 Sigmund 的 99 行 / 88 行程序。
- 固定面和受载面附近的材料会保持实体。
- 示例悬臂块保留 30% 材料时，刚度是实心零件的约 37%。


**生成报告**：计算或拓扑优化完成后，点底部「生成报告…」，选一个文件夹，会生成：

- **报告.docx**：中文科技论文排版，宋体 + Times New Roman，三线表，图题、表题自动编号。内容包括：
  - 概述、材料参数、约束和载荷
  - 结果表和结论、应力 / 强度利用率 / 位移云图
  - 网格收敛过程，或拓扑优化的设置和结果
  - 方法描述、适用范围、参考文献（GB/T 7714）
- **报告.md**：同样的内容，方便贴进 LaTeX、Typora 或笔记。
- **图\\**：300 dpi 的 PNG，可以直接放进论文。
- **数据\\**：CSV 原始数据。
  - 静力分析：结果汇总、收敛过程，以及全部节点的坐标、位移和应力。
  - 拓扑优化：迭代历史、优化后外形的 STL。
- **方法描述（可直接用于论文）.txt**：一段写好的方法描述，带参考文献编号和参考文献列表。

**要知道的地方**：

- 这是**线弹性静力分析**：适用于应力低于屈服强度、变形不大的情况。不包括接触、螺栓预紧、塑性、大变形、屈曲、振动和疲劳。
- 只分析单个零件，不算装配体里零件之间的接触。
- 复合材料按各向同性等效，只能粗略估计；铺层方向、层间强度、开孔和连接处要单独校核。
- 3D 打印件层与层之间的强度可能只有标称值的一半左右，受力方向垂直于打印层时安全系数建议取 3 以上。
- 网格划分用的是开源的 Gmsh（GPL 许可，程序文件夹里的 `gmsh` 文件夹，附带许可证）。求解器和拓扑优化是本程序内置的，不需要 SolidWorks Simulation。

## 可制造性检查

左侧点「可制造性」，把零件（.sldprt / .step / .stp / .stl）拖进来，在上方选工艺：FDM 打印、光固化或 CNC。只读取零件，不会修改它。页面上有三个示例（悬垂件、薄壁件、CNC 件），可以先试一下。

- **3D 打印**：
  - 检查悬垂（默认 45° 规则，可调）、薄壁（FDM 0.8 mm、光固化 0.5 mm，可调）、小孔，以及是否超出打印机尺寸。
  - 自动在 200 多个方向里找支撑最少、最稳的摆放方向，给出前 3 个，点一下就换。
  - 估算支撑体积、用料、重量、材料费和打印时间。
- **CNC**：
  - 按刀具可达性算出最少要几次装夹，并找出从哪个方向都加工不到的倒扣。
  - 检查以下问题：
    - 立铣刀做不出的尖内角
    - 只能用小刀的内圆角
    - 深宽比大于 4 的深腔、窄槽
    - 深径比大于 10 的深孔
    - 薄壁
    - 建模没对齐留下的细缝
  - 估算毛坯、加工时间和费用。
- **右侧每条问题**：都有严重程度、数值和具体怎么改。点一下，3D 视图会转过去并高亮；零件内部的问题会把零件变成半透明显示。
- **生成报告**：生成 Word 报告，包括方法、引用文献、300 dpi 的图、问题清单和修改建议；同一文件夹里还有 Markdown 和 CSV 原始数据。

时间和费用是按经验参数估算的，只用来比较方案，以切片软件或加工厂的报价为准。用已知尺寸的测试件核对过（发布版的「示例\可制造性」）：悬垂面积、支撑体积、0.5 mm 薄壁、T 型槽倒扣面积、深孔深径比、尖内角和 R1 内圆角都和手算一致。

局限：
- 深腔只按平底测量。
- 刀具可达性按直线视线判断，不考虑刀柄碰撞。
- 支撑按竖直投影估算，不模拟树状支撑。

## 工作区：同名文件检查、版本历史、崩溃找回

左侧点「工作区」，把项目文件夹拖进来（或点「添加工作区」）。工具只读取，不会改动你的文件。

- **重名检查**：SolidWorks 按文件名认文档。内存里已经有一个「支架.SLDPRT」时，再打开的装配体会直接用它，不管当初引用的是哪个文件夹里的。工具会列出工作区里的同名文件：内容不同的标「危险」，内容相同的标「副本」；同一组里内容相同的文件，标的字母相同。
- **检查全电脑**：找工作区外面的同名文件。会跳过系统和程序目录，几十万个文件只要几秒。
- **检查装配体引用**：在后台 SolidWorks 里进行，不打开文档。报出以下几种情况：
  - 缺失
  - 会用错文件：记录的文件和 SolidWorks 实际会加载的不是同一个，而且内容不同
  - 位置变了
  - 引用了工作区外的文件
- **版本历史**：
  - 软件开着时，你在 SolidWorks 里每保存一次就自动留一份；内容没变的不重复存。改大版本前可以点「全部存档」并写一句备注。
  - 想退回时，在文件的版本列表里点「恢复」，恢复前会先把当前文件存一份。文件正在 SolidWorks 里打开时，要先关闭它。
  - 历史库放在 `%LOCALAPPDATA%\SwKit\history`，不往项目文件夹写东西。每个文件保留 20 个版本、总共不超过 2 GB，都可以改。
- **崩溃找回**：列出 SolidWorks 自己的自动恢复和备份文件，可以另存出来。SolidWorks 正常关闭时会删掉它们；崩溃后，重新打开 SolidWorks 之前先来这里看看。

命令行：`swkit-cli ws dup D:\项目 --global`、`swkit-cli ws refs D:\项目`、`swkit-cli ws snapshot D:\项目`、`swkit-cli ws restore <文件> <版本>`。

## AI 控制接口：让你的 AI 直接操控这个软件

左侧点「AI 控制接口」。打开「允许 AI 操控本软件」后（默认打开），你的 AI 就能直接用这个软件的所有功能，界面会实时显示 AI 在做什么：
- 导出
- 生成 URDF
- 生成标准件和装配
- 应力分析和拓扑优化
- 检查工作区
- 截图看界面

- **Claude Code**：在终端运行页面上给出的一行命令（`claude mcp add swkit -- "…\swkit-cli.exe" mcp`）。以后直接对 Claude 说「用 SW 工具箱分析 D:\零件\支架.sldprt，底面固定，顶面加 500 N 向下的力」。
- **Claude Desktop、Cursor 等支持 MCP 的客户端**：把页面上的 JSON 配置加进客户端的 MCP 配置，重启客户端。软件没开时，AI 第一次调用会自动把它打开。
- **Cherry Studio、VS Code（Copilot / Cline）、Trae、Windsurf、Gemini CLI**：都支持 MCP，配置写法和 Claude Desktop 一样。
- **GPT**：ChatGPT 网页版和桌面版只能连公网上的服务，连不到你电脑上的程序。可以用 OpenAI 的 Codex CLI（在 ~/.codex/config.toml 里加 [mcp_servers.swkit]，页面上有现成的配置），或者用下面的通用方式。
- **任何大模型（GPT、DeepSeek、通义、Kimi、智谱、豆包、本机 Ollama 等，只要兼容 OpenAI 接口）**：在终端运行 swkit-cli agent --provider deepseek（或 qwen / openai / kimi / zhipu / doubao / siliconflow / ollama，也可以用 --base-url 填任意地址），直接用中文对话，模型会调用软件完成任务。
  - 密钥从环境变量读（例如 DEEPSEEK_API_KEY）或用 --key 传入，不保存。
  - 对话内容只发给你指定的模型服务。
- **只能填网址的 MCP 客户端**：填 http://127.0.0.1:47821/mcp?token=令牌（HTTP 版 MCP）。
- **Dify、Coze、LangChain 等**：可以直接导入 http://127.0.0.1:47821/api/openapi.json（OpenAPI）或 /api/openai-tools（函数调用定义）。
- **自己写脚本**：本地 HTTP 接口 `POST http://127.0.0.1:47821/api/<页面>/<操作>`，请求体是 JSON 参数，请求头带 `X-SwKit-Token`。端口和令牌在 `%APPDATA%\SwKit\api.json`。页面右侧列出了所有操作和参数。

安全：
- 接口只监听本机（127.0.0.1），每个请求都要带令牌。令牌第一次启动时生成后保持不变（方便配置客户端），可以在页面上点「重新生成令牌」。
- 网页无法读取令牌文件，也无法跨域带自定义请求头，所以浏览器里的网页调用不了这个接口。
- 不想让 AI 操控时，在页面上关掉开关即可。

## 界面：高分辨率屏幕和缩放

- 程序按每块屏幕各自的缩放比例清晰显示。4K 200% 和笔记本 150% 混用、在两块屏幕之间拖动窗口时，都不会发虚。窗口大小按屏幕可用区域自动计算。
- **Ctrl + 滚轮**（或 Ctrl + = / Ctrl + −）整体放大缩小界面，**Ctrl + 0** 还原。设置会记住。
- 3D 视图拖动时，每帧只更新一次视角；模型很大时，拖动过程中临时关闭抗锯齿，松开后恢复。

## 速度和占用

- **求解器**：用光滑聚集代数多重网格做预条件（和 ANSYS、Trilinos 等同一类方法），迭代次数基本不随网格加密而增加。
  - 2.7 万单元：9 秒 → 3 秒
  - 理论解验证算例：17 秒 → 3.6 秒
  - 拓扑优化：68 秒 → 27 秒

  精度和以前完全一致。
- **网格**：Gmsh 改用 HXT 算法、单线程，比以前快约 40%，而且同样的输入每次得到同样的网格，结果可以复现。
- **不和你抢电脑**：计算期间软件自动降到「低于正常」优先级，你同时在用 SolidWorks 不会卡。算完立刻把大块内存还给系统。
- **少等 SolidWorks**：
  - 往「一键导出」里拖文件的那一刻，就开始在后台启动 SolidWorks，等你选好格式时它基本已经就绪。
  - 应力分析用过的零件，STEP 转换结果会缓存，零件没改过就不再启动 SolidWorks。
  - URDF 的零件几何也会缓存。
  - 缓存在 %LOCALAPPDATA%\SwKit\cache，有大小上限，会自动清理。
- **后台 SolidWorks**：空闲 10 分钟后自动关闭，也可以在左下角状态卡里随时手动关闭。
