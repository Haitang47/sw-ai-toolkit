# SW 工具箱 使用说明

## 需要什么

- Windows 10 或 11（自带 .NET Framework 4.8，不用另外安装任何东西）
- SolidWorks 2023 及以上版本

把整个文件夹放在任意位置，双击 `SwKit.exe` 就能用，不需要安装。

## 一键导出

1. 把 SolidWorks 文件或整个文件夹拖进窗口，也可以点"选择文件"或"选择文件夹"。文件夹会自动查找里面所有的零件、装配体和工程图。
2. 在右侧勾选要导出的格式：
   - 零件 / 装配体：STEP、STL、3MF、Parasolid、IGES、钣金展开 DXF
   - 工程图：PDF、DWG、DXF
3. 按需调整选项，然后点"开始导出"。

设置会自动保存，下次打开还是一样。

### 几个要知道的地方

- **不会打扰你手头的工作。** 导出在后台另外启动的一个隐藏 SolidWorks 里进行，你可以继续在自己的 SolidWorks 里画图。
- **第一次导出要等 20–60 秒**，用来启动后台 SolidWorks。之后 10 分钟内再导出不用等；空闲 10 分钟或者关闭本程序时，后台 SolidWorks 会自动关闭。
- **导出的是磁盘上已保存的版本。** 在 SolidWorks 里还没保存的修改不会包含在内。
- **STL 默认保持模型原坐标**（不平移到正空间），导出 URDF 网格或多零件对位打印时请保持打开。
- **STEP 提供 AP214 和 AP203。** 实测 SolidWorks 的接口设成 AP242 时，实际输出的还是 AP203，所以没有提供 AP242 选项。
- 导出的扩展名统一为小写（例如 `.stl`），避免在 Linux 下（例如 ROS）因为大小写对不上而找不到文件。
- 钣金展开 DXF 只对钣金零件生效，其他零件会自动跳过。

### 出问题时

- 列表里每个文件都会显示结果；点底部"显示日志"可以看详细过程，"复制全部"可以把日志发给维护的同事。
- "文件是用更高版本的 SolidWorks 保存的"：这个文件需要用更新版本的 SolidWorks 才能打开。
- "目标文件被其他程序占用"：先关掉正在打开这个输出文件的程序（例如切片软件）。

## URDF 导出

1. 把装配体（.sldasm）拖进"URDF 导出"页面，或点"选择装配体"。程序会在后台 SolidWorks 里只读打开它，分析配合，识别关节。
2. 左边是 3D 预览（左键拖动旋转，右键拖动平移，滚轮缩放）；右边是识别出的关节。拖动每个关节的"预览"滑条，看机器人动得对不对。
3. 需要时修改关节类型、反转轴向、改运动范围，填好机器人名，点"导出 URDF"。

导出的是一个 ROS 功能包，文件夹名为 `<机器人名>_description`，**同一个包在 ROS 1（Noetic / Melodic）和 ROS 2 里都能直接编译**：

| 文件 | 用途 |
| --- | --- |
| `urdf/<机器人名>.urdf` | 网格用 `package://` 路径，ROS 里用 |
| `urdf/<机器人名>_standalone.urdf` | 网格用相对路径，直接拖进其他 URDF 查看器、PyBullet、MuJoCo 用 |
| `meshes/*.stl` | 每个连杆一个外观网格，单位米。细节特别多的连杆会自动简化到 20 万个三角形以内 |
| `meshes/collision/*.stl` | 碰撞网格，每个连杆简化到 2 万个三角形以内，MoveIt / Gazebo 做碰撞检测快很多 |
| `launch/display.launch` | ROS 1：`catkin_make` 后 `roslaunch <包名> display.launch` |
| `launch/display.launch.py` | ROS 2：`colcon build` 后 `ros2 launch <包名> display.launch.py` |
| `校验报告.md` | 导出后自动检查的结果，见下文 |

两个 launch 都会打开 RViz 和关节滑条窗口，需要 `robot_state_publisher` 和 `joint_state_publisher_gui`（ROS 桌面版自带；精简安装的 Noetic 上缺的话：`sudo apt install ros-noetic-robot-state-publisher ros-noetic-joint-state-publisher-gui`）。

**没有配合也能导 URDF**：默认「配合 + 几何」模式以配合为准；没有配合的零件，按零件形状推断关节：
- 同轴的轴和孔
- 轴承内孔
- 电机 / 舵机输出端（自动判断哪一侧是输出端）
- 光轴和直线轴承
- 导轨

如果配合把所有零件都锁死了，会自动改为只按几何。也可以手动切到「只按几何」，忽略配合重新识别，不用重新打开 SolidWorks。

推断出的关节在 3D 预览里标为紫色，并给出依据和置信度。把握不大的列为「建议」、默认不启用，在类型里改成转动或移动即可启用。零件之间留了间隙（没有接触）时，无法推断它们之间的关节，会按位置固定在最近的零件上。零件几何会缓存到 %LOCALAPPDATA%\SwKit\cache，零件没改过，第二次分析会快很多。

在三个真实装配体上，完全不看配合、只按几何推断：
- 四旋翼倾转机构装配体：4 个关节全部找对
- 测试机械臂：找到 2/3
- 无人机 + 机械臂装配体：17 个关节找到 12 个

轴线误差都是 0。

### 怎么识别关节

- 程序把每个配合换算成约束，算出两个零部件之间还剩几个自由度：剩 0 个就并成同一个连杆，剩 1 个转动就是转动关节，剩 1 个平移就是移动关节。
- **转动关节**用"同心 + 端面重合"（或铰链配合）效果最好；**移动关节**用两组面重合（或平行 + 重合）。
- **运动范围**：有角度 / 距离**限位配合**时直接读出来（显示"来自限位配合"）；没有时转动默认 ±180°，移动默认 ±50 mm，需要你改成实际值。
- **子装配体**默认会展开，按里面的配合识别关节（夹爪、舵机模块常常放在子装配体里）。这包括 SolidWorks 里的**刚性**子装配体，虽然它们在 SolidWorks 里整体不能动。不想要时，关掉顶部的"分析子装配体内部"，刚性子装配体就整体当作一个零件（柔性子装配体总是展开）。
- **闭链**会整体分析：例如一块板同时和基座、电机输出轴同心，单看每一对零件都还能转，但合起来其实被锁死了，程序会把它并进基座，不会误报关节。真正能动的闭链（例如四连杆）URDF 表示不了，会断开一处并提示。
- 螺钉、铝柱、电机外壳这类**绕自身轴对称、只能空转**的末端零件，会默认按固定连接导出，并折叠在列表最后（标着"可空转"）。
- 名字里带"桨、旋翼、轮、风扇"或 prop / rotor / wheel / fan 的零件，按**连续转动**导出。参与齿轮配合的零件保持转动。
- 齿轮、齿条、螺旋、联轴配合不会生成 URDF 的 mimic 关系，会在提示里列出来。
- 只剩约束不足（还能自由移动多个方向）的零部件，按固定连接导出并在提示里列出。子装配体里完全没有配合的零部件跟着该子装配体一起动。

### 坐标系约定

- 根连杆是装配体里**固定**的零部件；没有固定零部件时取最重的一组，并给出提示。
- 零位就是装配体当前的姿态。所有连杆坐标系都与世界坐标轴平行，原点放在关节轴上，所以 URDF 里 `rpy` 全是 0，读起来最直观。
- SolidWorks 默认 Y 向上，导出时会转成 ROS 的 Z 向上。如果你的模型本来就是 Z 向上，在顶部选"Z 向上"。
- 导出时，固定连接（空转的螺钉、垫片、约束不全的零件，以及你设成"固定"的关节）连着的零件会**并入上级连杆**，URDF 里只留下真正能动的关节。连杆和关节的名字和界面里一致，所以编号可能不连续。命令行加 `--keep-fixed` 可以保留每个固定连接。

### 导出后的自动检查

程序会把写出的 URDF 重新读进来检查，结果写在 `校验报告.md`，界面右侧也会显示：

- **结构**：连杆和关节构成一棵树，名字不重复，关节轴是单位向量，范围合理。
- **质量与惯量**：每个连杆的惯量矩阵正定、满足三角不等式；读到的零件质量合计与 SolidWorks 的装配体总质量一致；没设材料的零件会列出来（按 1000 kg/m³ 计算）；隐藏的零件不计入 URDF，会说明少了多少质量。
- **网格**：每个网格文件都在、不是空的，尺寸合理（能查出毫米当成米）；网格体积和质量能对上（对不上通常是网格不封闭或质量被覆盖）。
- **零位**：按读回的 URDF 计算零位姿态，每个零件的网格都要回到 SolidWorks 里的位置（误差超过 0.1 mm 算错误）。这一项能查出坐标系、关节原点写错。
- **关节轴**：每个运动关节的轴线要和配合给出的轴线重合，否则转起来会绕错轴。
- **质心**：零件网格的体积质心和 SolidWorks 算出的质心对比，独立检查网格的坐标和单位。个别零件对不上通常是零件设置了质量覆盖、含有隐藏实体或多种材料（URDF 里用的是 SolidWorks 的质量和质心，不受影响），只做提醒；大多数零件都对不上才算错误。

### 要知道的地方

- 分析的是**磁盘上已保存的版本**，装配体不会被修改，也不会在 SolidWorks 里新建坐标系。
- 第一次分析要等后台 SolidWorks 启动（20–60 秒），大装配体打开和导出网格也需要一些时间。

## 标准件库

1. 在「标准件库」页面左边选零件类型（左上角可以搜索名称、标准号或型号，例如 M3、608、GT2、LM8UU、ISO 4762，回车选第一个），右边点选规格、长度等参数，中间实时预览，并显示外形尺寸、体积和估算质量。
2. 点「生成零件」。零件在后台 SolidWorks 里用原生特征（拉伸、旋转、切除）建出来，保存为 .SLDPRT。需要的话打开底部的「同时导出 STEP / STL」。
3. 生成的文件出现在右下「已生成」列表里，**按住拖进 SolidWorks 的装配体窗口**就能插入。

一共 60 种零件，9 个分类：

| 类别 | 零件 |
| --- | --- |
| 紧固件 | 内六角圆柱头 / 沉头 / 半圆头螺钉、十字盘头螺钉、外六角螺栓、法兰螺栓、紧定螺钉（平端 / 锥端 / 凹端）、六角螺母、尼龙锁紧螺母、法兰螺母、平垫圈、大垫圈、弹簧垫圈、圆柱销、弹性销、抽芯铆钉、热熔铜螺母、铜柱、型材 T 型螺母 |
| 轴承 | 深沟球轴承、法兰轴承、推力轴承、带座轴承 UCP / UCF |
| 直线运动 | 直线轴承 LM-UU（含加长型、法兰型）、光轴、光轴支座 SK、直线导轨和滑块（MGN / HGR）、梯形丝杆和螺母（T8）、滚珠丝杆和螺母（SFU） |

| 电机 | 步进电机 NEMA8 / 11 / 14 / 17 / 23、舵机、N20 / 130 减速电机、TT 马达、无刷电机 |

**装配生成**（选「装配生成」分类）：

- **齿轮副（按中心距）**：输入中心距和传动比，自动列出可行的模数和齿数方案。能凑整的用标准齿轮，凑不整的用变位齿轮精确凑出中心距，同时检查根切。生成的装配体带 SolidWorks 齿轮配合，拖动一个齿轮，另一个会跟着转；可以选择同时生成带轴承孔的安装板。
- **铝型材框架**：输入长 × 宽 × 高和型材系列（2020 / 3030 / 4040），生成 12 根型材 + 16 个角码的立方框，附切割清单（每种长度几根）。
- **同步带传动**：输入两个带轮的齿数和大致中心距，自动选标准闭口带长、反算精确中心距，并检查啮合齿数。

生成的装配体都会做干涉检查，结果显示在底栏。

几个要知道的地方：

- 文件默认保存在 `文档\SW工具箱\标准件\<类别>\`，可以在底部更改。同一个规格生成过，就直接使用已有文件，不再启动 SolidWorks。
- 每个零件都带自定义属性（名称、标准、规格、Description、材料说明），工程图明细表可以直接引用。
- 螺纹按光杆画（和 Toolbox 的简化画法一样）。
- 以下是简化外形：轴承、T 型槽内腔、带轮和链轮齿形、挡圈耳部、槽钢和工字钢的翼缘斜度。电机、舵机、开发板是包络外形，误差约 ±0.5–1 mm，质量请按实物另设。
- 生成后会把 SolidWorks 算出的体积和理论体积对比，确认建模没有出错。全部 207 个样本规格都在 SolidWorks 里验证过，体积误差最大 0.135%（齿轮）。

## 应力分析

第一次用，可以先点页面上的「示例：L 形支架」或「示例：悬臂块拓扑优化」，约束和载荷都已经设好，直接看效果。页面上方有一条分步引导，会提示现在该做哪一步；「使用指南」里有完整说明。

1. 把零件（.sldprt、.step 或 .stp）拖进「应力分析」页面。.sldprt 会在后台 SolidWorks 里转成 STEP，并读出零件的材料。
2. 右侧选材料，按类别分组，共 33 种：
   - 钢、不锈钢：Q235、Q355、45 钢、40Cr、65Mn、灰铸铁、304、316、17-4PH
   - 铝合金：6061-T6、6063-T5、7075-T6、2A12、5052、压铸铝
   - 钛合金：TC4、TA2
   - 铜合金：黄铜、锡青铜
   - 复合材料：碳纤维板、碳纤维管、FR4 玻纤板、玻纤尼龙
   - CNC 常用工程塑料：POM、MC 尼龙、PEEK、PC、亚克力
   - 3D 打印：PLA、PETG、ABS、PA-CF、光敏树脂

   也可以选「自定义」，自己填弹性模量、泊松比、强度和密度。

   零件在 SolidWorks 里设了材料，会自动对应到这里的材料；**没设材料**（或者是 STEP / STL）时按文件名猜，例如文件名里有「碳板」「碳纤」就用碳纤维板，有「铝」「6061」就用 6061-T6。顶部会写明是怎么选的，不对就在右侧改。
3. 在 3D 视图里**单击选面**（按住 Ctrl 多选），在弹出的条上点：
   - **固定**：螺栓孔、安装面等。至少要有一个固定面。
   - **加力**：总力（N），方向选 ±X / ±Y / ±Z，或「垂直压向面」。
   - **加压力**：压强（MPa），垂直压向面。
   - **加扭矩**：扭矩（N·m），绕所选面的轴（适合轴的圆柱面、法兰端面）。

   整个零件的重力或加速度惯性力在右侧「加重力 / 加速度」里添加。方向用零件坐标系（SolidWorks 里 Y 向上），视图里有红绿蓝三根轴对应 X / Y / Z。
4. 点「开始计算」。左上角可以切换四种显示：
   - **等效应力**：塑性材料看它。
   - **最大主应力**：脆性材料看它。
   - **位移**
   - **强度利用率**：应力 ÷ 强度，超过 100% 会失效。

   黑点是最大值的位置；「显示变形」可以看放大后的变形。

**多工况**（零件会遇到好几种受力时）：

- 一个零件在使用中往往不止一种受力。例如无人机机架：满油门爬升、偏航急转、侧面磕碰、硬着陆；支架：正常工作、安装时拧螺丝、跌落。只按一种受力设计，换一种受力可能就不行了。
- 在右侧「载荷」下点「+ 加工况」，每种受力建一个工况：**约束所有工况共用，载荷各工况分开**。上面的按钮切换正在编辑的工况，在左边选面加的载荷就加到这个工况；可以改名字、复制为新工况（同时乘一个倍数，例如满油门 = 悬停 × 2）、删除。
- **多旋翼常用工况**：先把悬停时的受力设好（每个电机座的螺丝孔加一个推力，最好再加反扭矩，相邻电机反向），点「生成多旋翼常用工况」，会按推重比 2 自动生成：
  - 满油门：推力和反扭矩 × 2；
  - 偏航急转：反扭矩同向的一组电机 1.6 倍、另一组 0.4 倍；
  - 侧面磕碰：第一个电机座受 2 倍推力的水平侧向力（垂直于机臂）；
  - 硬着陆：每个电机座受 3 倍推力向下（约 3 g 冲击）。

  这些是常用的估计值，可以在每个工况里按自己的情况改。
- **计算**：所有工况一起算（只组装一次刚度矩阵、建一次预条件，多一个工况只多几秒）。结果默认显示**包络**：每个点取所有工况里最危险的值，安全系数取最小；右侧列出每个工况的最大应力、安全系数和位移，标出最危险的工况，也可以切换只看某一个工况。
- **拓扑优化 / 凸边布局**：同时兼顾所有工况。目标是各工况柔度的加权和；每个工况先除以实心零件在这个工况下的柔度，所以大小差很多的工况（例如 50 N 的推力和 5 N 的侧碰）同样重要。每个工况有「权重」（默认 1），某种受力更重要就调大。结果会列出每个工况保留了多少刚度。
- 报告里会列出每个工况的载荷和结果。

**失效判据**：
- 钢、铝、钛、铜、多数塑料是塑性材料，按 von Mises 等效应力对比屈服强度。
- 铸铁、碳纤维、玻纤、亚克力、光敏树脂是脆性材料，按最大主应力对比抗拉强度，最小主应力对比抗压强度。

安全系数取两者中较危险的位置。

**结果准不准**：

- 求解器是二次四面体单元（和 SolidWorks Simulation 的「高品质」网格同一类）。用拉杆、悬臂梁、带孔板孔边应力集中、扭转轴、自重悬臂梁的理论解核对过，误差 0.04%–2%。
- 每次计算都会给出**估计误差**（Zienkiewicz–Zhu 误差估计，能量范数）：3% 以内很好，8% 以内可以接受。同时检查求解是否收敛、外载和支撑反力是否平衡。
- **自适应加密**：只在误差大的地方加密网格并重算，直到估计误差低于 3%、离开约束面的最大应力变化小于 3%，最多 3 轮。思路和 SolidWorks Simulation 的 H 自适应相同。右侧会列出每一轮的单元数、最大应力和误差。
- **尖角**（没有圆角的内角）和**固定面边缘**的应力在数学上是无穷大，会随网格加密一直升高，这不是真实应力。程序会提示这种情况，并单独给出「离开固定面后的最大应力」；要知道尖角处的真实应力，给它加上真实的圆角再算。

**拓扑优化**（结构优化）：

1. 设好固定面和载荷（和应力分析一样），点底部「拓扑优化…」。
2. 选**形式**：
   - **自动**（默认）：识别出薄板（板厚不到面内尺寸的 15%）就按板件优化，否则按三维。
   - **板件**：只开沿板厚方向的穿透孔，结果可以直接激光 / 水刀 / CNC 切板（碳板、铝板、玻纤板、钣金）。做法是同一列单元共用一个密度（拉伸约束）。
   - **三维**：可以挖出不穿透的槽和筋，适合 CNC 铣削、3D 打印、铸造件。
   - **凸边布局**（只有薄板才有这一项）：板本身不变，在板的上下表面外面各加一层「凸边高度」厚的材料，优化器决定这一层里哪些地方留下来当筋。结果就是**凸边 / 加强筋应该画在哪里**。可以选凸边高度（零件已经有凸边时默认取现有的高度）、加在两面 / 上面 / 下面，以及凸边用料占这一层的比例（默认 12%）。结果分上层、下层两张图显示，并给出凸边用了多少克、刚度是凸边层全填满时的百分之几。
     - 约束和载荷要加在**孔（圆柱面）或板的侧面**上：板的上下表面加了凸边层以后变成了内部面，加在上面的会被忽略并提示。
     - 零件会遇到好几种受力时，先建好多个工况（见上面的「多工况」），凸边布局会同时兼顾所有工况。
     - 用法：先用平板（没有凸边的版本）做「凸边布局」，看筋该放哪；再按结果画出凸边，回到「开始计算」对比加凸边前后的位移和应力。
     - 以 X 形机臂底板（3 mm 碳板，电机推力 + 反扭矩，固定中心的连接孔）为例：优化出来的筋沿机臂中线，从根部的固定孔一直到减重孔结束、机臂变宽的地方，上下对称；电机附近和外轮廓都不需要。按这个画的中线筋（7 × 2 mm，两面，穿过根部孔）和同样重量的「外圈一圈凸边」相比，电机端挠度小 36%、最大应力小 28%。筋不要在固定孔前面突然断掉（那样刚度突变，孔边应力反而会升高），要穿过或包住孔。
3. 选**保留的材料比例**（20%–60%，常用 30%–50%）和**细节程度**：粗约 2.5 万单元，标准约 6 万，细约 12 万。薄板会自动把网格加密到板厚方向至少两层单元。
4. 点「开始优化」。可以实时看到材料一点点被去掉，标准细节大约 1–3 分钟。
5. 结果给出保留的材料、保留的刚度（相对实心零件）和减重。点「导出 STL」得到优化后的外形（毫米），在 SolidWorks 里作为参考重新建模，再回来做应力校核。

**约束和载荷要加得像真实情况**，这是结果对不对的关键：
- 固定：选真实的安装位置——螺栓孔的圆柱面、安装座的小平面。**不要固定整块板的大面**，否则整块都不能动，优化不出传力路径。
- 载荷：力从哪里进来就加在哪里。**不要把力加在整块板的上表面**，那样力会平均摊到整个面上，和电机、螺栓传力完全不同。
- 选孔：点一个孔的圆柱面，再点弹出条上的「**选同组孔**」，会一次选中同样大小、挨在一起的所有孔（例如同一个电机座的 4 个螺丝孔，每个孔通常是两个半圆柱面）。
- 例：多旋翼机架底板（X 形一体机臂）。只固定和机身连接的孔（例如上下板连接柱）；电池、飞控的安装孔加它们的重量（向下的力）；每个电机座的孔各加一个**力**（升力，单个电机的最大推力）和一个**扭矩**（反扭矩，绕电机轴，相邻电机方向相反）。结果是机臂根部保留得最宽（升力产生的弯矩在根部最大），靠近电机的一段开大孔，四条机臂经过电池 / 飞控孔连到中心。
- **不要把中心所有孔都固定**：固定的孔之间等于焊在了地上，它们之间的材料不传力，会被整片挖掉，结果看起来中心板「没了」。
- 如果约束或载荷选了很大的面，右侧会在开始前就提示；优化后保留比例比目标高出 10% 以上，会明确提示「没有效果」和原因，不会给出一个看起来正常的结果。

方法是 SIMP 密度法：
- 加上体积加权的密度过滤和 Heaviside 投影，用最优准则法更新；这是学术界和商业软件最常用的方法，参考 Sigmund 的 99 行 / 88 行程序。β 增大后自动减小移动步长，避免结果来回振荡。
- 安装孔、受力孔附近的材料会保持实体；很大的约束 / 受载面不算（否则整块板都会变成「必须保留」）。
- 示例悬臂块保留 30% 材料时，刚度是实心零件的约 37%。


**生成报告**：计算或拓扑优化完成后，点底部「生成报告…」，选一个文件夹，会生成：

- **报告.docx**：中文科技论文排版，宋体 + Times New Roman，三线表，图题、表题自动编号。内容包括：
  - 概述、材料参数、约束和载荷
  - 结果表和结论、应力 / 强度利用率 / 位移云图
  - 网格收敛过程，或拓扑优化的设置和结果
  - 方法描述、适用范围、参考文献（GB/T 7714）
- **报告.md**：同样的内容，方便贴进 LaTeX、Typora 或笔记。
- **图\\**：300 dpi 的 PNG，可以直接放进论文。
- **数据\\**：CSV 原始数据。
  - 静力分析：结果汇总、收敛过程，以及全部节点的坐标、位移和应力。
  - 拓扑优化：迭代历史、优化后外形的 STL。
- **方法描述（可直接用于论文）.txt**：一段写好的方法描述，带参考文献编号和参考文献列表。

**要知道的地方**：

- 这是**线弹性静力分析**：适用于应力低于屈服强度、变形不大的情况。不包括接触、螺栓预紧、塑性、大变形、屈曲、振动和疲劳。
- 只分析单个零件，不算装配体里零件之间的接触。
- 复合材料按各向同性等效，只能粗略估计；铺层方向、层间强度、开孔和连接处要单独校核。
- 3D 打印件层与层之间的强度可能只有标称值的一半左右，受力方向垂直于打印层时安全系数建议取 3 以上。
- 网格划分用的是开源的 Gmsh（GPL 许可，程序文件夹里的 `gmsh` 文件夹，附带许可证）。求解器和拓扑优化是本程序内置的，不需要 SolidWorks Simulation。

## 可制造性检查

左侧点「可制造性」，把零件（.sldprt / .step / .stp / .stl）拖进来，在上方选工艺。工艺分三组：

- **3D 打印**：FDM 打印、光固化、尼龙烧结（SLS / MJF）、金属打印（SLM / DMLS）
- **切削**：CNC 铣削、板材切割（CNC 雕刻 / 激光 / 水刀切 2D 平板，例如碳板）
- **成形**：钣金（激光切割 + 折弯）、注塑

只读取零件，不会修改它。页面上有五个示例：悬垂件、薄壁件、CNC 件、钣金支架、碳板机臂。

- **FDM / 光固化**：检查悬垂（默认 45° 规则，可调）、薄壁（FDM 0.8 mm、光固化 0.5 mm，可调）、小孔、是否超出打印机；在 200 多个方向里找支撑最少、最稳的摆放方向（推荐前 3 个，点一下就换）；估算支撑、用料、材料费和打印时间。光固化还会提示封闭空腔（困树脂）。
- **尼龙烧结（SLS / MJF）**：
  - 不需要支撑，所以不检查悬垂，摆放只影响高度。
  - 检查：
    - 尺寸和孔：薄壁（SLS 0.8 mm、MJF 0.7 mm）、孔径小于 1.5 mm、是否放得进成型仓。
    - 缝隙：小于 0.5 mm 的缝会被烧结粘死。
    - 封闭空腔：粉末出不来，要开 2 个以上排粉孔（SLS ≥ Φ5、MJF ≥ Φ3.5）。
    - 翘曲：大面积薄平板容易翘。
  - 估算：按零件体积 + 包围盒体积估价，按高度估打印时间。
- **金属打印（SLM / DMLS）**：
  - 检查：
    - 悬垂和摆放：45° 悬垂和推荐摆放方向；Φ8 以下的水平孔能自支撑，更大的建议改泪滴形。
    - 支撑能否取出：封闭流道 / 内腔里的支撑取不出来。
    - 其他：封闭空腔、残余应力（大平面平行于基板）、薄壁、缝隙。
  - 材料：AlSi10Mg / 316L / Ti6Al4V / 18Ni300。
  - 估算：打印费、后处理费、打印时间。工艺提示里列出后处理步骤（线切割下基板、去应力热处理、去支撑、喷砂、配合面留余量）。
- **CNC 铣削**：
  - 按刀具可达性算出最少要几次装夹，找出从哪个方向都加工不到的倒扣。
  - 检查立铣刀做不出的尖内角、只能用小刀的内圆角、深宽比大于 4 的深腔 / 窄槽、深径比大于 10 的深孔、薄壁、建模留下的细缝。
  - 估算毛坯、加工时间和费用。
- **板材切割**：适合碳纤维板、玻纤板、铝板、钢板、亚克力这类 2D 平板零件（例如无人机机架板）。
  - 自动识别板面和板厚。只有垂直贯穿的外形和孔能直接切出来；凸起、沉槽、沉头孔、倒角都会标成「要另外铣」，碳板会提示铣表面会切断纤维、强度下降。
  - CNC 雕刻会检查：
    - 内角：至少留刀具半径的圆角，尖内角建议倒圆或开狗骨头避空。
    - 窄槽和小孔：槽比刀窄铣不出来，孔比刀小要换钻头。
  - 所有方式都会检查：
    - 筋宽和孔边距：碳板筋宽 ≥ max(t, 2 mm)，孔到板边 ≥ 1.5t。
    - 小孔：激光切金属要孔径 ≥ 板厚。
    - 工艺和材料搭不搭配：例如碳板不适合激光切。
  - 估算切割长度、轮廓数、加工时间、材料费和切割费。
  - 和应力分析里拓扑优化的「板件」模式配合用：拓扑优化只开穿透孔，结果拿到这里检查筋宽、孔边距和内角。
- **钣金**：
  - 自动识别板厚。不是等厚板会直接提示不能做钣金，并建议用 SolidWorks 钣金特征重建。
  - 检查：
    - 折弯内半径：按材料判断，冷轧钢 ≥ 1t，6061-T6 ≥ 2–3t（建议换 5052）。
    - 尖角折弯，以及「内侧圆角、外侧尖角」这类用实体拉伸画出来的拐角。
    - 折边长度：外尺寸 ≥ max(4t, 3t + R)。
    - 孔和开口：离折弯 ≥ 2t + R、离板边 ≥ 1.5t、孔径 ≥ 板厚；还有窄槽、沉头孔 / 斜边、止裂槽提示。
  - 估算展开面积、折弯数、切割长度、重量、材料费 + 激光切割 + 折弯费用。
  - 建议用 STEP；STL 没有面信息，识别不出折弯。
- **注塑**：
  - 自动选倒扣最少的开模方向（可以点其他候选方向）。
  - 检查：
    - 倒扣：判断用滑块（给出侧抽方向）还是斜顶。
    - 拔模：侧壁拔模角小于 0.5° 必须修改，小于 1° 建议修改。
    - 壁厚：局部厚壁会缩痕 / 气孔，建议掏空加筋；薄壁、流长比。
    - 尖内角（建议 R ≥ 0.5t），细长型芯。
  - 估算锁模力、成型周期、单件料费和机时、模具费区间，以及 N 件时的单价。
- **右侧每条问题**：都有严重程度、数值和具体怎么改。点一下，3D 视图会转过去并高亮；零件内部的问题会把零件变成半透明显示。
- **生成报告**：生成 Word 报告，包括方法、引用文献、300 dpi 的图、问题清单、修改建议和工艺提示；同一文件夹里还有 Markdown 和 CSV 原始数据。
- **命令行**：`swkit-cli dfm 零件.step sheet`，工艺代号是 fdm、sla、sls、slm、cnc、cut、sheet、mold。可以加 `--material`、`--machine`、`--method router|laser|waterjet`、`--cutter`、`--qty`、`--report`。

时间和费用按国内常见报价的经验参数估算，只用来比较方案，以切片软件或加工厂报价为准。用已知尺寸的测试件核对过（发布版的「示例\可制造性」）：悬垂面积、支撑体积、0.5 mm 薄壁、T 型槽倒扣面积、深孔深径比、尖内角和 R1 内圆角、钣金展开面积和切割长度都和手算一致。

局限：
- 钣金只估展开面积，不算展开尺寸。
- 注塑不画分型线，模具费是按尺寸和滑块数分档的粗略区间。
- 深腔只按平底测量。
- 刀具可达性按直线视线判断，不考虑刀柄碰撞。
- 支撑按竖直投影估算，不模拟树状支撑。

## 质量估算

左侧点「质量估算」，把装配体拖进来（.sldasm / .sldprt / .step / .stp / .stl），会列出每一种零件和它用了几个，给每种零件选材料，算出总质量、重心和按材料分的小计。只读取，不会修改文件。

- **零件和数量**：
  - .sldasm：在后台 SolidWorks 里只读打开，子装配体会展开到零件。同一个零件（同一个文件、同一个配置）用了几次就算几个。
  - 体积和质心取 SolidWorks 的精确值；压缩的零部件、封套不计入。
  - STEP / STL：按实体拆开，形状相同的实体合并计数，内部空腔会扣掉。读不出零件名，按「实体 1、2……」编号。体积按贴合曲面的二次曲边三角形积分：圆柱、圆孔、球面也基本精确（和理论值差 0.02% 以内）；STL 本身就是折面，按 STL 的折面算。
- **选材料**：点每一行的材料按钮，弹出材料表，共 100 种左右，可以按类别找或者直接搜索：
  - 金属：钢 / 铸铁、不锈钢、铝合金（6061、7075、5052、6063、2A12、压铸铝……）、镁、钛、铜和其他金属（含配重、磁铁）。
  - 复合材料：碳纤维板 / 管、玻纤板、芳纶。
  - 塑料和软材料：工程塑料（ABS、PC、尼龙、POM、PEEK、亚克力……），橡胶和硅胶。
  - 3D 打印：FDM（PLA、PETG、PA-CF……）、光固化树脂、尼龙烧结（SLS / MJF）、金属打印（AlSi10Mg、316L、Ti6Al4V……）。
  - 其他：木材 / 泡沫（巴沙木、层板、EPP……）等。
- **批量设材料**：勾选多个零件（表头的方框是全选，也可以先搜索再全选），点「给勾选的零件设材料」。点「勾选没选材料的」可以一次选中所有还没设材料的零件。
- **自动带出材料**：
  - SolidWorks 里设过材料的零件，自动对应到材料表；对应不上的直接用 SolidWorks 里的密度。
  - 没设材料的按文件名猜，例如「碳板」→ 碳纤维板，「6061」→ 6061 铝。
  - 你选过的材料会记住（按零件文件 + 配置），下次打开同一个装配体、或者别的装配体用到同一个零件时自动带上。
- **外购件**：电机、电池、电调这类建模简化过的零件，在材料弹窗下面填「实测单件质量」，就按称出来的质量算。参考件、示意件可以设为「不计入总质量」。
- **FDM 打印件**：按「外壳 + 填充」算，质量 = 表面积 × 外壳厚度 + 其余体积 × 填充率。填充率和外壳厚度在右侧调（默认 15%、0.8 mm）。其他工艺按实心算。
- **结果**：
  - 总质量，还没选材料的零件会单独提示，不会悄悄算成 0。
  - 重心：.sldasm 是装配体坐标系，和 SolidWorks 里一致。
  - 按材料的小计和占比，每一行底部的橙色条是这个零件占总质量的比例。
- **导出**：「导出清单（CSV）」可以用 Excel 打开；「复制清单」可以直接粘贴到 Excel / 飞书 / 微信。
- **命令行**：`swkit-cli mass 装配体.sldasm --material "6061-T6 铝" --csv 清单.csv`，`swkit-cli mass materials` 列出全部材料和密度。
- **AI 接口**：mass_load、mass_parts、mass_set_material（可以用 "unassigned" 一次设好所有没选材料的零件）、mass_set_measured、mass_summary 等。

## CFD 流场

左侧点「CFD 流场」，把整机拖进来（.sldasm / .sldprt / .step / .stp / .stl），放上转子和涵道，算出周围的气流：下洗、桨和桨之间的干扰、机身受到的下洗力、涵道的附加推力，并画出按速度着色的流线。第一次用可以点「示例：四旋翼悬停」，桨盘已经放好。

- **桨叶不用建模**：每个转子 / 涵道风扇当成一个「作动盘」——一个给定推力的圆盘，在盘面上把空气往推力的反方向推。模型里有桨叶也可以，计算前会提示把它隐藏或删掉（真实的桨叶要转起来才有意义）。
- **放桨盘**：
  - 「四旋翼模板」：填轴距（对角电机距离）、桨径、盘面高度和每个桨的推力，一次放 4 个，X 或 + 布局，相邻两个桨反转。
  - 「+ 加一个」后点「在模型上点选位置」，在电机顶面上点一下，桨盘中心就放在那里；「+ 加涵道」用于涵道风扇（推力方向一般是水平的，盘面放在涵道里）。
  - 每个桨盘可以改中心、推力方向、直径、桨毂直径、推力、反扭矩、旋向，以及推力沿半径的分布：「均匀」或「接近真实桨」（外侧推力大、桨毂附近小）。
  - 「按起飞重量分配推力」：填起飞重量，悬停时平分给所有转子（会先扣掉涵道推力的竖直分量），反扭矩按桨径估算。
- **计算设置**：
  - 计算设备：有显卡时默认用显卡（OpenCL，NVIDIA / AMD / Intel 都可以），比 CPU 快几十倍；没有就用 CPU。显存临时不够时会等几秒再用显卡试一次，仍然不够才改用 CPU。
  - 网格：显卡上粗 / 标准 / 细约 150 万 / 500 万 / 1200 万格（CPU 上是 50 万 / 150 万 / 300 万），下面会显示格子大小和需要的显存。桨盘直径少于 10 个格子时会提示选「细」。
  - 来流：0 是悬停；前飞时填飞行速度和「空气相对飞机吹向哪里」。
  - 地面效应：打开后填离地高度，计算域底部变成地面。
- **计算时**：右侧实时显示过桨盘中心的竖直切面速度。示例四旋翼 500 万格在 RTX 5070 Ti 上约 20 秒。
- **结果**：
  - 总推力、机身受到的下洗力（占推力的百分比）和净升力；每个实体分别受多大的力。
  - 每个桨盘的平均入流速度，和孤立桨的动量理论值对比：比理论值大说明受到别的桨或机身干扰，要多费功率才能产生同样的推力。
  - 流线：可以选从盘面进口、桨尖外圈、盘面上方出发，以及显示竖直切面；颜色是速度（m/s）。「保存图片…」存成 PNG；「导出 VTK…」导出时间平均速度场，可以用 ParaView 打开做更多后处理。
- **设置会记住**：同一个模型的桨盘和计算设置会保存，下次打开同一个文件自动带上。
- **准不准**：
  - 求解器是格子玻尔兹曼方法（LBM，D3Q19，正则化碰撞 + Smagorinsky 大涡模拟），固体用反弹边界，作动盘用体积力，机身受力用动量交换法。
  - 单个作动盘：下游的动量通量等于推力的 98%–101%，远尾流速度约为盘面诱导速度的 2.0–2.1 倍，和动量理论一致。
  - 圆球阻力（Re = 100）：比经验公式高约 11%（球直径只有 16 个格子时的典型误差，格子越细越准）。
  - 适合看流动趋势、比较方案（例如机臂放在下洗里挡掉多少推力、两个桨间距多大合适）。作动盘不模拟桨叶的翼型、失速和噪声；格子比机臂、薄板厚度粗时，这些小零件的受力只能粗略估计。
- **AI 接口**：cfd_load、cfd_quad、cfd_add_disk、cfd_settings、cfd_run、cfd_result、cfd_export_vtk 等。

## 工作区：同名文件检查、版本历史、崩溃找回

左侧点「工作区」，把项目文件夹拖进来（或点「添加工作区」）。工具只读取，不会改动你的文件。

- **重名检查**：SolidWorks 按文件名认文档。内存里已经有一个「支架.SLDPRT」时，再打开的装配体会直接用它，不管当初引用的是哪个文件夹里的。工具会列出工作区里的同名文件：内容不同的标「危险」，内容相同的标「副本」；同一组里内容相同的文件，标的字母相同。
- **检查全电脑**：找工作区外面的同名文件。会跳过系统和程序目录，几十万个文件只要几秒。
- **检查装配体引用**：在后台 SolidWorks 里进行，不打开文档。报出以下几种情况：
  - 缺失
  - 会用错文件：记录的文件和 SolidWorks 实际会加载的不是同一个，而且内容不同
  - 位置变了
  - 引用了工作区外的文件
- **版本历史**：
  - 软件开着时，你在 SolidWorks 里每保存一次就自动留一份；内容没变的不重复存。改大版本前可以点「全部存档」并写一句备注。
  - 想退回时，在文件的版本列表里点「恢复」，恢复前会先把当前文件存一份。文件正在 SolidWorks 里打开时，要先关闭它。
  - 历史库放在 `%LOCALAPPDATA%\SwKit\history`，不往项目文件夹写东西。每个文件保留 20 个版本、总共不超过 2 GB，都可以改。
- **崩溃找回**：列出 SolidWorks 自己的自动恢复和备份文件，可以另存出来。SolidWorks 正常关闭时会删掉它们；崩溃后，重新打开 SolidWorks 之前先来这里看看。

命令行：`swkit-cli ws dup D:\项目 --global`、`swkit-cli ws refs D:\项目`、`swkit-cli ws snapshot D:\项目`、`swkit-cli ws restore <文件> <版本>`。

## AI 控制接口：让你的 AI 直接操控这个软件

左侧点「AI 控制接口」。打开「允许 AI 操控本软件」后（默认打开），你的 AI 就能直接用这个软件的所有功能，界面会实时显示 AI 在做什么：
- 导出
- 生成 URDF
- 生成标准件和装配
- 应力分析和拓扑优化
- 检查工作区
- 截图看界面

- **Claude Code**：在终端运行页面上给出的一行命令（`claude mcp add swkit -- "…\swkit-cli.exe" mcp`）。以后直接对 Claude 说「用 SW 工具箱分析 D:\零件\支架.sldprt，底面固定，顶面加 500 N 向下的力」。
- **Claude Desktop、Cursor 等支持 MCP 的客户端**：把页面上的 JSON 配置加进客户端的 MCP 配置，重启客户端。软件没开时，AI 第一次调用会自动把它打开。
- **Cherry Studio、VS Code（Copilot / Cline）、Trae、Windsurf、Gemini CLI**：都支持 MCP，配置写法和 Claude Desktop 一样。
- **GPT**：ChatGPT 网页版和桌面版只能连公网上的服务，连不到你电脑上的程序。可以用 OpenAI 的 Codex CLI（在 ~/.codex/config.toml 里加 [mcp_servers.swkit]，页面上有现成的配置），或者用下面的通用方式。
- **任何大模型（GPT、DeepSeek、通义、Kimi、智谱、豆包、本机 Ollama 等，只要兼容 OpenAI 接口）**：在终端运行 swkit-cli agent --provider deepseek（或 qwen / openai / kimi / zhipu / doubao / siliconflow / ollama，也可以用 --base-url 填任意地址），直接用中文对话，模型会调用软件完成任务。
  - 密钥从环境变量读（例如 DEEPSEEK_API_KEY）或用 --key 传入，不保存。
  - 对话内容只发给你指定的模型服务。
- **只能填网址的 MCP 客户端**：填 http://127.0.0.1:47821/mcp?token=令牌（HTTP 版 MCP）。
- **Dify、Coze、LangChain 等**：可以直接导入 http://127.0.0.1:47821/api/openapi.json（OpenAPI）或 /api/openai-tools（函数调用定义）。
- **自己写脚本**：本地 HTTP 接口 `POST http://127.0.0.1:47821/api/<页面>/<操作>`，请求体是 JSON 参数，请求头带 `X-SwKit-Token`。端口和令牌在 `%APPDATA%\SwKit\api.json`。页面右侧列出了所有操作和参数。

安全：
- 接口只监听本机（127.0.0.1），每个请求都要带令牌。令牌第一次启动时生成后保持不变（方便配置客户端），可以在页面上点「重新生成令牌」。
- 网页无法读取令牌文件，也无法跨域带自定义请求头，所以浏览器里的网页调用不了这个接口。
- 不想让 AI 操控时，在页面上关掉开关即可。

## 检查更新 / 一键更新

左下角（SolidWorks 状态上面）有一行小字「v版本 检查更新」。

- **自动检查**：软件每天最多自动到 GitHub 查一次新版本（打开几秒后在后台查，查不到、没网都不会打扰你）。有新版本时，左下角会出现蓝色小卡片「有新版本 vX」。
- **手动检查**：点「检查更新」，结果直接显示：「已经是最新版本」「有新版本」或「连不上 GitHub」。
- **看更新内容**：点卡片上的「看更新内容」，在软件里直接看这个版本改了什么，不用开浏览器。
- **一键更新**：点「更新」：
  1. 自动下载安装程序（约 35 MB，卡片上显示进度，随时可以「取消」）；
  2. 核对文件大小和 SHA-256，和 GitHub 上公布的一致才安装；不一致会删掉下载的文件，不安装；
  3. 软件自动关闭 → 安装 → 自动重新打开（大约十几秒）。

  如果还有任务在进行（例如正在导出），会先问你要不要关闭；选「否」就不更新，下载好的安装程序会留着，下次点「更新」直接安装。

你的设置、工作区历史、材料记忆和 AI 接口令牌保存在 %APPDATA%\SwKit、%LOCALAPPDATA%\SwKit，更新不会动它们。

**安装版和绿色版**

| | 安装版（用安装程序装的） | 绿色版（解压 zip 用的） |
|---|---|---|
| 更新到哪里 | 原来的安装文件夹 | 原来那个文件夹，就地替换文件 |
| 「设置 → 应用」里的版本号 | 自动改成新版本 | 不登记（和原来一样） |
| 桌面 / 开始菜单快捷方式 | 保持原样，不会新建 | 不会新建 |

- 软件放在需要管理员权限的文件夹（例如 C:\Program Files）时没法自动更新，卡片上会提示，请点「打开下载页」手动下载。
- 同一个文件夹里的 SW 工具箱开了两个窗口时，请先关掉另一个；放在其他文件夹里的副本不受影响。
- AI 客户端开着 swkit-cli（MCP）也能更新，重启 AI 客户端后就用上新版本。

**连不上 GitHub 怎么办**

GitHub 在国内有时连不上或很慢。出现「连不上 GitHub」或「下载失败」时：

1. 过一会儿点「重试」，或换个网络（例如手机热点）、打开代理 / VPN 后再试（软件使用系统代理设置）；
2. 或者点「打开下载页」，在浏览器里下载 `SWKit-v版本-Setup.exe`（安装版，装到原来的文件夹即可覆盖升级）或 `SWKit-v版本-portable.zip`（绿色版，解压覆盖原来的文件夹）；
3. 下载中断或校验不通过时不会安装任何东西，原来的软件照常可用。

AI 也可以帮你查：AI 控制接口里的 `app_check_update` 会返回当前版本、最新版本和更新内容（只查不装，更新需要你自己点「更新」）。

> 在线更新从 v0.7 开始支持；v0.6 及更早的版本需要手动下载安装一次 v0.7（装到原来的文件夹即可覆盖）。

## 界面：高分辨率屏幕和缩放

- 程序按每块屏幕各自的缩放比例清晰显示。4K 200% 和笔记本 150% 混用、在两块屏幕之间拖动窗口时，都不会发虚。窗口大小按屏幕可用区域自动计算。
- **Ctrl + 滚轮**（或 Ctrl + = / Ctrl + −）整体放大缩小界面，**Ctrl + 0** 还原。设置会记住。
- 3D 视图拖动时，每帧只更新一次视角；模型很大时，拖动过程中临时关闭抗锯齿，松开后恢复。

## 速度和占用

- **求解器**：用光滑聚集代数多重网格做预条件（和 ANSYS、Trilinos 等同一类方法），迭代次数基本不随网格加密而增加。
  - 2.7 万单元：9 秒 → 3 秒
  - 理论解验证算例：17 秒 → 3.6 秒
  - 拓扑优化：68 秒 → 27 秒

  精度和以前完全一致。
- **网格**：Gmsh 改用 HXT 算法、单线程，比以前快约 40%，而且同样的输入每次得到同样的网格，结果可以复现。
  - 孔很多的薄板（例如带几十个小孔的碳板）在「细」网格下自由度可能超过 60 万，多重网格放不下，普通预条件又很慢。这时会自动把孔边的加密放宽、网格稍微放粗，把规模控制在多重网格能处理的范围内，并在右侧说明。
  - 曲面附近偶尔有二次单元被网格程序弯「翻」（常见于很薄的台阶、两个同轴的孔接在一起），会自动把这几个单元拉直再计算，结果里会注明个数。
- **不和你抢电脑**：计算期间软件自动降到「低于正常」优先级，你同时在用 SolidWorks 不会卡。算完立刻把大块内存还给系统。
- **少等 SolidWorks**：
  - 往「一键导出」里拖文件的那一刻，就开始在后台启动 SolidWorks，等你选好格式时它基本已经就绪。
  - 应力分析用过的零件，STEP 转换结果会缓存，零件没改过就不再启动 SolidWorks。
  - URDF 的零件几何也会缓存。
  - 缓存在 %LOCALAPPDATA%\SwKit\cache，有大小上限，会自动清理。
- **后台 SolidWorks**：空闲 10 分钟后自动关闭，也可以在左下角状态卡里随时手动关闭。
